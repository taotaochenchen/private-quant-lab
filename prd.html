📋 1. 产品概述

本产品是一个面向个人投资者或小型投资团队的全自动 AI 量化交易系统。系统完全由 Agent 自主决策，覆盖从盘前分析、标的筛选、风控审核到自动下单和盘中调仓的完整交易链路。用户不参与日常交易决策，仅保留系统级监督权和紧急停止权。

核心定位

全自动、无人值守的量化交易系统。大模型负责推理与决策，量化算子负责计算与约束，独立风控持有否决权。

用户角色

用户只查看系统运行状态、持仓和复盘报告。唯一手动入口是紧急停止按钮。

关键边界

不是"大模型荐股工具"，而是有严格风控、可熔断、可审计的自动交易执行系统。

👤 2. 用户画像与使用场景

目标用户
  • ✅ 个人量化投资者 — 有编程/量化基础，希望解放日常看盘精力，信任系统化交易逻辑。
  • ✅ 小型投资团队 — 2-5 人团队，需要统一决策框架和完整审计日志。
  • ✅ 策略研究者 — 希望快速验证多 Agent 协作的交易工作流，保留完整证据链用于回测优化。
核心使用场景
📅 每日开盘前自动启动 → 📊 全市场扫描与情绪分析 → 🏭 行业筛选与个股下钻 → 🧮 算子评分与风控审核 → 📤 自动下单执行 → 🔄 盘中监控与调仓 → 📝 收盘自动复盘

🏗️ 3. 系统架构总览

系统采用「Agent 集群 + 确定性算子 + 独立风控引擎 + 自动交易执行」四层架构，所有模块异步协作，通过消息队列传递结构化数据。

决策层（Agent 集群）
├── 总控 Agent（盘前指挥官）
├── 市场情绪 Agent
├── 行业研究 Agent（可并行多实例）
├── 个股发现 Agent
├── 金融算子 Agent
├── 反方观点 Agent
├── 风控 Agent（独立否决权）
├── 交易计划 Agent
├── 交易执行 Agent
├── 盘中监控 Agent
└── 收盘复盘 Agent
基础设施层
├── 数据采集服务（行情/新闻/资金/公告/宏观）
├── 数据标准化服务（统一字段/时间/代码）
├── 因子计算服务（确定性算子库）
├── 风控引擎（独立进程，硬性约束）
├── 订单管理服务（订单状态机）
├── 持仓同步服务（实时账户状态）
├── 决策记录存储（证据链/审计日志）
├── 消息队列（Agent 异步通信）
└── 复盘服务（策略评价与优化）
💡
关键设计原则：大模型 Agent 只负责推理和决策生成，所有数字必须来自确定性算子。风控引擎是独立进程，拥有硬性否决权，可随时阻断订单发出。

⚙️ 4. 核心功能模块

4.1 盘前自动分析
  • 定时任务调度，无需人工触发
  • 自动拉取行情、新闻、资金、公告、宏观数据
  • 数据完整性检查，缺失时自动降级或暂停交易
  • 输出盘前分析快照和今日交易模式
4.2 市场情绪分析
  • 量化情绪温度分数（0-100）
  • 资金强度分数、波动风险分数
  • 自动输出交易模式：进攻/防守/轮动/空仓
  • 输出量化禁忌条件，直接供风控引擎使用
4.3 行业深度研究
  • 全市场扫描，自动筛选 2-4 个候选行业
  • 评估政策催化、景气度、资金流入、估值、拥挤度
  • 输出行业评分、证据链、反方观点、失效条件
  • 支持并行分析多个行业
4.4 个股发现与算子评估
  • 仅在已选行业内筛选，避免全市场无约束扫描
  • 过滤低流动性、财报窗口、监管风险标的
  • 调用确定性算子计算质量、动量、估值、波动、流动性、拥挤度、盈利修正、风险事件等因子
  • 输出结构化评分，大模型不得修改任何数字
4.5 独立风控引擎
  • 单股/单行业/总仓位自动限制
  • 单日最大亏损熔断（触发后自动平仓并禁止开仓）
  • 账户最大回撤熔断
  • 流动性检查（订单量不超过日成交量阈值）
  • 高波动环境自动降杠杆/降仓
  • 财报/公告/解禁窗口自动禁止开仓
  • 自动设置止损单、止盈单
4.6 自动交易执行
  • 交易计划 Agent 生成结构化订单指令
  • 对接券商 API，自动提交、撤单、重试
  • 成交回报自动同步，支持部分成交处理
  • 断线重连与订单状态恢复
  • 盘中监控 Agent 自动触发加仓/减仓/止损/止盈

🔄 5. 自动化交易流程（无人干预）

每日定时启动（开盘前 N 小时）
        ↓
自动数据采集与健康检查
        ↓
市场情绪 Agent 自动分析 → 输出情绪/资金/波动分数 + 交易模式
        ↓
总控 Agent 决定今日交易模式（进攻/防守/轮动/空仓）
        ↓
行业研究 Agents 并行筛选 → 输出 2-4 个候选行业
        ↓
反方观点 Agent 校验 → 寻找逻辑漏洞和潜在风险
        ↓
个股发现 Agent 下钻 → 输出候选股票池
        ↓
金融算子 Agent 计算评分 → 所有因子值来自确定性算子
        ↓
风控 Agent 独立审核 → 可降仓 / 否决 / 熔断
        ↓
交易计划 Agent 生成订单指令 → 结构化下单参数
        ↓
自动交易执行模块发送订单 → 券商 API 自动执行
        ↓
盘中监控 Agent 跟踪触发条件 → 自动调仓/止损/止盈
        ↓
收盘复盘 Agent 自动记录与评价 → 策略优化建议
⚠️
人工干预唯一入口：紧急停止按钮。用户可在任意时刻手动暂停系统，系统会立即撤销所有未成交订单，并停止一切交易活动。恢复运行需人工确认。

🛡️ 6. 风控体系（独立硬性约束）

风控引擎是独立于所有 Agent 的进程，拥有最高权限。任何交易指令必须通过风控引擎审核，否则订单不会发出。

风控规则 触发条件 执行动作 恢复条件
单日最大亏损熔断 当日累计亏损 ≥ 账户净值的 2% 自动平仓全部持仓，禁止新开仓 下一交易日人工重置
账户最大回撤熔断 从历史峰值回撤 ≥ 10% 自动降仓至 30% 以下，暂停自动交易 回撤恢复至 5% 以内，人工确认
单股仓位限制 单只股票持仓占比 > 12% 自动减仓至 12% 以内 实时监控，自动执行
单行业仓位限制 单一行业持仓占比 > 40% 自动减仓至 40% 以内 实时监控，自动执行
流动性检查 订单数量 > 该股日均成交量的 5% 自动缩减订单数量 重新评估后执行
财报/公告窗口 未来 3 个交易日内有财报披露 自动禁止开仓，已有持仓可持有 窗口期过后自动解除
相关性检查 推荐标的之间相关系数 > 0.75 自动降低总仓位 20% 实时评估，自动执行
订单频率限制 单只股票日内订单数 > 10 笔 自动暂停该股票交易 下一交易日自动解除

🗄️ 7. 数据架构与证据链

数据分层
1. 原始数据层    — 外部数据源原始结果（带时间戳/版本）
2. 标准化数据层  — 统一字段、时间、代码、行业分类
3. 因子数据层    — 算子计算结果（可复现）
4. 决策记录层    — 每日 Agent 输出、评分、建议、证据
5. 订单数据层    — 所有订单、成交、撤单记录
6. 复盘层        — 实际行情、执行结果、策略评价
证据链结构（最小示例）
{
  "evidence_id": "evt_20260905_001",
  "type": "news_sentiment",
  "source": "mock_news_api",
  "source_timestamp": "2026-09-05T00:30:00Z",
  "value": { "sentiment": 0.62, "headline_count": 120 },
  "used_by": ["market_sentiment_agent"],
  "influence": "将情绪温度从55上调至62"
}
🔒
数据质量硬性要求：关键字段缺失时，系统自动暂停交易。多数据源冲突时，标记不确定性并降低仓位。所有最终结论必须能追溯到具体数据源和时间戳。

⚠️ 13. 风险与合规

🔴
高危风险提示：全自动交易系统一旦出现 Bug，可能在极短时间内造成重大资金损失。以下措施为强制性要求，不可妥协。
硬性安全措施
  • 硬编码熔断：当日亏损达阈值自动平仓并停止交易
  • 单日最大交易次数限制
  • 订单频率限制，防止异常下单
  • 账户权限分离，限制最大可亏损金额
  • 模拟盘先行：实盘前至少 1 个月模拟验证
  • 紧急停止开关：可随时手动暂停系统
合规要求
  • 遵守券商 API 使用规范
  • 不得进行市场操纵
  • 完整审计日志：所有决策、订单、风控事件可追溯
  • 用户明确知晓并签署风险确认书
  • 系统输出不构成投资建议，风险自担
